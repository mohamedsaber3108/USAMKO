   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

2. Add to .env.local:
   ENCRYPTION_MASTER_KEY=<generated-key>

3. Install WebSocket dependencies:
   npm install @nestjs/websockets @nestjs/platform-socket.io socket.io

4. Start PostgreSQL and run migrations:
   npx prisma migrate dev --name add_credential_vault_and_audit_log

5. Encrypt existing tokens:
   npx ts-node scripts/encrypt-existing-tokens.ts

6. Start the API:
   npm run dev
